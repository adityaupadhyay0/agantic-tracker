# AGENTS.md - CORTEX Project Guidelines

## Core Directives
1. **Privacy First:** Never collect or log raw message content or document content. Use metadata only.
2. **Local-First Architecture:** Assume the system runs within a customer's firewall. Use `docker-compose` for orchestration.
3. **Ontology Adherence:** All behavioral states must map to the CORTEX Ontology defined in the SRS.
4. **BCO as Atomic Unit:** Every insight must be wrapped in a Behavioral Context Object (BCO).

## Tech Stack
- **Backend:** FastAPI, SQLAlchemy (Postgres), Pydantic, ChromaDB (Vector Search).
- **Frontend:** Next.js, Tailwind CSS, Lucide-React.
- **AI Integration:** OpenAI API (GPT-4o/GPT-4o-mini).

## Development Patterns
- Use Pydantic for all data validation and schema definitions.
- Implement clear service layers for Interpretation, Compression, and Retrieval.
- Frontend should focus on transparency and utility for both individuals and AI systems.

## Testing
- Use `pytest` for backend unit and integration tests.
- Use Playwright for frontend verification.
- Provide a `simulate_telemetry.py` script for end-to-end testing of the pipeline.
